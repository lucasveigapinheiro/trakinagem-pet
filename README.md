# Trakinagem Pet Shop — Site institucional

Site institucional para o **Trakinagem Pet Shop**, em Nova Petrópolis, São Bernardo do Campo. Apresenta banho, tosa, atendimento veterinário e o serviço de leva e traz, com agendamento direto pelo WhatsApp.

## Destaques

- Página única com serviços, história, avaliações, dicas de cuidado, depoimentos e localização
- Animações de entrada e de scroll com **GSAP**, respeitando `prefers-reduced-motion`
- Botões de agendamento via WhatsApp com mensagem pronta
- Meta tags de SEO e compartilhamento
- Layout responsivo, 100% estático

## Tecnologias

HTML5, CSS3, JavaScript, GSAP.

## Como rodar

Abra o `index.html` no navegador ou sirva a pasta com:

```bash
npx serve .
```

## Estrutura

```
index.html    # Página única
css/          # Estilos
js/main.js    # Animações e interações
assets/       # Imagens e ícones
```
